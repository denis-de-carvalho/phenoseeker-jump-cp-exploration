# Phenotypic Profiling on JUMP-CP - A Reproduction & Exploration Study

This repository contains a personal exploration of phenotypic compound profiling on the JUMP-CP Cell Painting dataset, building on the Phenoseeker pipeline from Sanchez et al. (*Communications Biology*, 2025).

## Goals

1. Reproduce a small-scale version of the Phenoseeker pipeline on a tractable subset of JUMP-CP.
2. Extract DINOv2-based phenotypic embeddings from cell images and apply batch correction.
3. Explore a simple methodological variant (e.g., comparison of normalization schemes).
4. Document the work clearly enough that any reader can re-run the analyses.

## Status

Work in progress - started May 2026. See `ROADMAP.md` for planned milestones.
